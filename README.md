# Isla Lite - Pixel Survival

Versi ringan game survival ala Durango dalam bentuk pixel 2D.  
Bisa dimainkan langsung di **GitHub Pages**, baik di PC maupun Android browser.

---

## 🎮 Cara Main

### Desktop (Laptop/PC)
- **Arrow Keys** = Bergerak
- **E** = Serang / Interaksi
- **I** = Buka Inventori
- **C** = Craft

Buka:  
```
https://username.github.io/nama-repo/index.html
```

### Android Browser
Gunakan versi khusus dengan tombol sentuh virtual.  
Buka:  
```
https://username.github.io/nama-repo/index_android.html
```

Tombol layar:  
- ⬆️⬇️⬅️➡️ = Gerak
- ⚔️ = Serang
- 🎒 = Inventori
- 🛠️ = Craft

---

## 📂 Struktur Repo
```
/index.html           -> versi utama (desktop)
/index_android.html   -> versi Android browser (touch controls)
/README.md            -> panduan ini
/assets/              -> (opsional) folder aset sprite, audio, font
```

---

## 💾 Fitur Game
- Bergerak & eksplorasi
- Serang dino kecil, loot meat
- Loot otomatis masuk inventori
- HUD (HP, Hunger, Stamina)
- Craft sederhana (campfire, pagar, berry snack)
- Pixel art sederhana (sprite kotak, mudah diganti dengan asset PNG)
